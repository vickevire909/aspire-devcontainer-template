# Repository instructions

## General

Always be concise and avoid giving the user unnecessary information.

Keep documentation as short and straight forward as possible.

After code changes, prefer hot reload or rebuilding/restarting only affected Aspire
resources. Restart the whole AppHost only when necessary.

## Git

Before git commits, use the `git-conventional-commits` skill at `.agents/skills/git-conventional-commits/SKILL.md`
